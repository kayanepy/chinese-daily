# Китайский каждый день

Личный сайт для разговорного китайского (HSK 1–4 по порядку, жизнь в Китае). Статический: только HTML/CSS/JS, работает на GitHub Pages.

- **Уроки** — 89 уроков по 15 слов: новые слова → грамматика → тоны (можно пропустить) → проверка слов → домашка по грамматике.
- **Карточки** — карточки с интервальным повторением (HSK 1–4 по уровням, слова для жизни в Китае, фразы). Режимы: читаю, слушаю, говорю.
- **Фразы** — 11 ситуаций: такси, метро, ресторан, магазин, аренда, банк, врач, доставка, разговор, экстренное.
- **Тоны** — тренажёр на слух и шпаргалка.
- **Грамматика** — около 40 тем HSK 1–4 с озвученными примерами.
- **Повтор** — свободная тренировка с вводом ответа (по дням, уровням, ситуациям, трудные слова) и примерами предложений.
- **Словарь** — поиск по иероглифам, пиньиню без тонов и по-русски.

Озвучка — встроенный синтез речи браузера (zh-CN), проверка произношения — распознавание речи (Chrome, Edge, Safari).
Прогресс хранится в браузере (localStorage); в настройках можно сохранить его в файл и загрузить на другом устройстве.

## Офлайн
Сайт — устанавливаемое веб-приложение (PWA): `manifest.webmanifest` + `sw.js` кэшируют все файлы, после первого открытия он работает без интернета. При обновлении файлов увеличьте `VERSION` в `sw.js`.

Все файлы лежат в корне (без папок) — так проще загружать через github.com.

Уроки: course-hsk1.js … course-hsk4.js — структура по HSK Standard Course 1–4 (порядок уроков, слова, темы грамматики); объяснения, диалоги и упражнения собственные, на русском. Движок уроков — lessons.js. Прогресс уроков хранится в S.course.
