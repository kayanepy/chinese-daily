# Как обновить сайт на GitHub (kayanepy/chinese-daily)

1. Распакуйте `chinese-daily.zip`. Все файлы лежат в одной папке, без подпапок.
2. Откройте репозиторий на github.com → **Add file → Upload files**.
3. Выделите и перетащите **все файлы** из распакованной папки. Одинаковые имена GitHub заменит сам.
4. Нажмите **Commit changes**.
5. Если в репозитории остались старые папки `css` и `js` — их можно удалить (открыть папку → ⋯ → Delete directory), они больше не нужны.
6. Через 1–2 минуты во вкладке Actions появится зелёная галочка — сайт обновлён.

# Установка на Android как приложение (офлайн)

1. Откройте https://kayanepy.github.io/chinese-daily/ в **Chrome** с интернетом. Внизу появится «Сайт сохранён для работы без интернета».
2. На главной нажмите **«Установить»**, или меню ⋮ → **«Установить приложение» / «Добавить на главный экран»**.
3. На экране появится иконка 中 — дальше открывайте сайт через неё, даже без интернета.

## Озвучка без интернета
Настройки Android → **Система → Язык и ввод → Синтез речи** (или «Преобразование текста в речь») → движок **Google** → ⚙️ → **Установить голосовые данные** → **Китайский (Китай / 普通话)** → скачать.

Проверка произношения 🎤 требует интернет и сервисы Google — в Китае работает только с VPN.

## Как приходят обновления
Приложение само подтягивает новую версию, когда телефон в сети. Обычно достаточно открыть его дважды.

## Китайская клавиатура (для ответов иероглифами)
Настройки → Система → Язык и ввод → Экранная клавиатура → **Gboard** → Языки → Добавить клавиатуру → **中文（简体）** → **Пиньинь**. Переключение — кнопкой 🌐 или долгим нажатием на пробел. Набираете «nihao» → выбираете 你好.
Если хотите, чтобы снова принимался пиньинь: ⚙️ Настройки сайта → снять «Отвечать только иероглифами».
